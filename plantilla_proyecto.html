Información del Proyecto

Fortaleza Assault 3D es una experiencia interactiva desarrollada con el motor gráfico Unity. El proyecto combina mecánicas tácticas en tiempo real con una interfaz fluida especialmente calibrada para pantallas táctiles y rendimiento optimizado en dispositivos móviles.

Características Principales:

  • Control táctil reactivo e interfaz adaptable.
  • Iluminación y sombras optimizadas para GPUs móviles.
  • Sistema de físicas 3D y colisiones avanzadas.
  • Arquitectura modular programada íntegramente en C#.

Ficha Técnica:

Motor Gráfico: Unity 3D
Lenguaje: C# Scripting
Plataforma: Android / PC Windows
Género: Estrategia / Acción 3D
